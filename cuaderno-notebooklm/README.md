# 📓 Cuaderno de Referencia (NotebookLM)

Esta carpeta está destinada a albergar todos los documentos, notas exportadas, guías de laboratorio, programas de estudio y material teórico proveniente de **NotebookLM**.

---

## 📂 Instrucciones de Uso

1. **Formatos Soportados**: Puedes agregar archivos `.md`, `.txt`, `.json` o `.pdf` exportados directamente de NotebookLM.
2. **Propósito**: Toda la información colocada en este directorio servirá como fuente de verdad para el diseño de nuevos simuladores, solucionadores de ecuaciones, ejercicios interactivos y contenidos para los módulos de pregrado.
3. **Sincronización**: Cada vez que agregues o actualices archivos aquí, el agente `github_sync_agent` los respaldará automáticamente en el repositorio de GitHub.
